## 📋 Task Description

The OpenCV Bootcamp is an official, beginner-friendly introduction to image processing with OpenCV. It covers:

- Reading and writing images and videos
- Image transformations (resize, crop, rotate, flip)
- Color space conversions
- Thresholding and contour detection
- Drawing shapes and annotations
- Basic video analysis
