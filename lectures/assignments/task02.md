## 📋 Task Description

The Kaggle Data Visualization course covers:

- Line charts and scatter plots with Matplotlib
- Bar charts, heatmaps, and distributions with Seaborn
- Choosing the right chart type for different data
- Styling and annotating visualizations

In computer vision, you will use these skills to:
- Plot image histograms and pixel distributions
- Visualize training/validation loss and accuracy curves
- Display image grids, bounding boxes, and class distributions
- Analyze dataset statistics
