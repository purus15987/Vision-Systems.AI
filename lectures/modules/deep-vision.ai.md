# 🧠 Module 6: Deep-Vision.AI – Deep Learning for Computer Vision

> **"Deep learning didn't just improve computer vision — it transformed it."**

---

## 📋 Module Overview

This module covers the full deep learning pipeline for computer vision: from CNNs and transfer learning to object detection, segmentation, and self-supervised methods.

---

## 🎯 Learning Objectives

- Build and train CNNs from scratch in PyTorch
- Apply transfer learning to custom datasets
- Implement object detection with YOLO and Faster R-CNN
- Perform semantic and instance segmentation
- Understand self-supervised and contrastive learning

---

## 📚 Topics Covered

### Week 16
- Convolutional Neural Networks (CNNs): architecture, training
- Batch normalization, dropout, data augmentation
- Transfer learning with ResNet, EfficientNet, MobileNet
- Fine-tuning strategies

### Week 17
- Object detection paradigms: one-stage vs two-stage
- YOLO (v5/v8): architecture, training, inference
- Faster R-CNN: RPN, ROI Pooling
- Evaluation: mAP, IoU

### Week 18
- Semantic segmentation: FCN, DeepLab, SegFormer
- Instance segmentation: Mask R-CNN
- Panoptic segmentation overview
- Practical: Custom YOLO training pipeline

---
