# 🚀 Module 9: Deploy-Vision.AI – Model Optimization & Deployment

> **"A model that can't be deployed is just a research paper."**

---

## 📋 Module Overview

This module covers the full deployment lifecycle of a vision model — from optimization and quantization to serving via REST APIs, containerization, and cloud deployment.

---

## 🎯 Learning Objectives

- Export models to ONNX format for cross-platform inference
- Optimize models with TensorRT for GPU acceleration
- Build REST APIs with FastAPI
- Create interactive vision apps with Streamlit
- Containerize applications with Docker
- Deploy to GCP Vertex AI and AWS SageMaker

---

## 📚 Topics Covered

### Week 24
- Model optimization overview: pruning, quantization, distillation
- ONNX export from PyTorch and TensorFlow
- TensorRT optimization pipeline
- Benchmarking: latency, throughput, memory
- Edge deployment: Raspberry Pi, Jetson Nano

### Week 25
- FastAPI: building vision inference endpoints
- Request handling: image upload, base64, multipart
- Streamlit: interactive vision demo apps
- Docker: containerizing the vision API
- Docker Compose for multi-service apps

### Week 26
- Cloud deployment fundamentals
- GCP Vertex AI: model registry, endpoints, online prediction
- AWS SageMaker: model packaging and endpoint deployment
- Monitoring and logging in production
- Final project presentations
