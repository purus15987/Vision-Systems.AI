# 🖼️ Module 1: DIP-Vision.AI – Digital Image Processing

> **"Every pixel tells a story."**

---

## 📋 Module Overview

This module introduces the foundational concepts of digital image processing — the gateway to all computer vision. You'll learn how images are formed, stored, and transformed at the pixel level.

---

## 🎯 Learning Objectives

By the end of this module, you will be able to:
- Understand image formation, digitization, and representation
- Perform pixel-level operations and transformations
- Apply histogram analysis and equalization
- Use spatial and frequency domain filtering
- Implement morphological operations
- Work with color spaces (RGB, HSV, LAB, Grayscale)

---

## 📚 Topics Covered

### Week 1
- Introduction to digital images (formation, sampling, quantization)
- Image types: Grayscale, RGB, Binary, Multispectral
- OpenCV basics: reading, writing, displaying images
- Pixel manipulation and NumPy array operations

### Week 2
- Intensity transformations: negative, log, gamma, power-law
- Histogram analysis and equalization
- CLAHE (Contrast Limited Adaptive Histogram Equalization)
- Color space conversions

### Week 3
- Spatial domain filtering: mean, median, Gaussian
- Custom convolution kernels
- Image sharpening (Laplacian, unsharp masking)
- Noise addition and removal

### Week 4
- Frequency domain: Fourier Transform, FFT
- Low-pass, high-pass, band-pass filters in frequency domain
- Morphological operations: erosion, dilation, opening, closing
- Practical: document binarization pipeline

---

## 🧰 Tools & Libraries

- **OpenCV** – core image processing
- **NumPy** – array operations
- **Matplotlib / scikit-image** – visualization and analysis
- **PIL/Pillow** – image I/O
