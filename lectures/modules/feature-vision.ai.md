# 🔍 Module 2: Feature-Vision.AI – Feature Detection & Image Representation

> **"The right features unlock the meaning hidden in every image."**

---

## 📋 Module Overview

This module covers classical feature detection, description, and matching — the backbone of pre-deep-learning computer vision and still essential for embedded, real-time, and interpretable systems.

---

## 🎯 Learning Objectives

- Detect edges, corners, and keypoints in images
- Compute and match feature descriptors
- Build image retrieval systems using Bag of Words
- Extract HOG and LBP features for classification
- Understand homography and image stitching

---

## 📚 Topics Covered

### Week 5
- Edge detection: Sobel, Prewitt, Canny
- Corner detection: Harris, Shi-Tomasi, FAST
- Blob detection: Laplacian of Gaussian (LoG), DoG

### Week 6
- Keypoint detectors and descriptors: SIFT, SURF, ORB, BRIEF
- Descriptor matching: BF Matcher, FLANN
- Geometric verification: RANSAC, Homography

### Week 7
- Bag of Visual Words (BoVW) for image retrieval
- HOG (Histogram of Oriented Gradients) for pedestrian detection
- LBP (Local Binary Patterns) for texture classification
- Practical: Building an image search engine

---

## 🧰 Tools

- **OpenCV** – feature detection and matching
- **scikit-image** – HOG, LBP
- **FAISS** – efficient feature search
