# 🏭 Module 5: Machine-Vision.AI – Industrial & Applied Vision Systems

> **"Precision and reliability — the hallmarks of machine vision."**

---

## 📋 Module Overview

This module focuses on applying computer vision in industrial and real-world settings — quality control, barcode scanning, OCR, measurement systems, and robotic vision.

---

## 🎯 Learning Objectives

- Design defect detection pipelines for manufacturing
- Use morphological operations for blob analysis
- Implement barcode and QR code detection
- Build OCR pipelines with Tesseract
- Understand measurement and calibration in industrial vision

---

## 📚 Topics Covered

### Week 14
- Industrial vision overview: applications and constraints
- Advanced morphological operations (top-hat, hit-or-miss)
- Blob analysis: connected components, contour analysis
- Defect detection on texture surfaces
- Practical: Automated defect inspection

### Week 15
- Barcode and QR code detection (pyzbar, OpenCV)
- OCR with Tesseract and EasyOCR
- Plate recognition pipeline (ANPR)
- Measurement systems: pixel-to-metric conversion
- Practical: Document digitization pipeline

---

## 🧰 Tools

- **OpenCV** – morphology, contours, blob analysis
- **Tesseract / EasyOCR** – text recognition
- **pyzbar** – barcode scanning
- **MVTec AD dataset** – defect detection benchmarks
