# 🤖 Module 8: Modern-Vision.AI – Vision Transformers & State-of-the-Art Architectures

> **"Transformers didn't just conquer NLP — they rewrote the rules of vision."**

---

## 📋 Module Overview

This module covers the paradigm shift brought by Vision Transformers (ViTs) and the latest state-of-the-art architectures for detection, segmentation, and open-vocabulary vision tasks.

---

## 🎯 Learning Objectives

- Understand the Vision Transformer (ViT) architecture
- Compare CNNs vs Transformers for vision tasks
- Implement ViT-based classification
- Work with DETR and Grounding DINO for detection
- Explore open-vocabulary and language-guided vision

---

## 📚 Topics Covered

### Week 22
- Self-attention mechanism recap (from NLP to vision)
- Vision Transformer (ViT): patch embedding, positional encoding
- DeiT — data-efficient image Transformers
- Swin Transformer — hierarchical shifted window attention
- ViT fine-tuning on custom datasets

### Week 23
- DETR — Detection Transformer (end-to-end object detection)
- Deformable DETR for faster convergence
- Grounding DINO — open-vocabulary object detection
- GLIP and OWL-ViT — language-image detection
- Practical: Build an open-vocabulary detector

---

## 🧰 Tools

- **Hugging Face Transformers** – ViT, DeiT, Swin, DETR
- **Grounding DINO** – open-vocabulary detection
- **PyTorch** – custom training
