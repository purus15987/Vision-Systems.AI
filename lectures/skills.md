# 🛠️ Skills & Tools Required – Vision-Systems.AI 2026

This page outlines the skills you'll need going in — and the ones you'll build by the end.

---

## 📌 Prerequisites (Before You Start)

### Programming
- [ ] Python basics (variables, loops, functions, classes)
- [ ] Familiarity with NumPy arrays
- [ ] Basic understanding of Matplotlib for plotting
- [ ] Git & GitHub basics (clone, commit, push)

### Mathematics
- [ ] Linear Algebra (vectors, matrices, dot products, eigenvalues)
- [ ] Calculus (derivatives, gradients — for understanding backprop)
- [ ] Basic statistics and probability

### Tools
- [ ] Python 3.10+ installed
- [ ] pip / conda package manager
- [ ] A Google account (for Colab)
- [ ] A GitHub account

---

## 🧠 Skills You Will Build

### Module 1–2: Image Processing & Features
- [ ] Image I/O, manipulation with OpenCV
- [ ] Histogram analysis and equalization
- [ ] Spatial filtering and convolution
- [ ] Edge detection, corner detection
- [ ] Feature descriptors (SIFT, ORB) and matching

### Module 3–4: Geometry & Video
- [ ] Camera calibration and distortion correction
- [ ] Stereo vision and depth estimation
- [ ] Optical flow computation
- [ ] Object tracking pipelines

### Module 5: Industrial Vision
- [ ] Morphological operations
- [ ] Defect detection pipelines
- [ ] OCR with Tesseract

### Module 6: Deep Learning
- [ ] Building and training CNNs in PyTorch
- [ ] Transfer learning and fine-tuning
- [ ] Object detection with YOLO
- [ ] Semantic and instance segmentation

### Module 7: Generative Models
- [ ] GAN training and inference
- [ ] Stable Diffusion image generation
- [ ] Using SAM, CLIP, and DINO

### Module 8: Vision Transformers
- [ ] ViT classification
- [ ] DETR and Grounding DINO inference
- [ ] Open-vocabulary detection

### Module 9: Deployment
- [ ] ONNX model export
- [ ] FastAPI REST endpoints
- [ ] Streamlit web apps
- [ ] Docker containerization
- [ ] Cloud deployment (GCP / AWS)
